Bug videos are also listed on the main bug page.

Confirmed bugs

#BugVideoExplanationSteps to recreateShould happenActually happens
9Due date before start date

What is wrong: A project can be given a due date that is earlier than its start date.

Why it is a bug: A project that ends before it begins is impossible — silently accepting it produces nonsense dates in lists, boards and recurring copies.

  1. Create or edit a project
  2. Set Start date = Nov 15, 2026
  3. Set Due date = Nov 10, 2026
  4. Save
Form blocks saving and shows 'Due date cannot be before start date'.Project saves with no warning; list shows due before start.
17Delete section containing tasks

What is wrong: Deleting a task section that still contains tasks silently deletes the tasks with it.

Why it is a bug: The confirm dialog is the generic 'delete this item?' — nothing says the section has tasks, and the tasks are not moved; they are gone. Data loss.

  1. Open a project's Tasks tab
  2. Delete a section that contains tasks
  3. Confirm the generic 'delete this item?' dialog
Warn 'this section contains N tasks' and offer to move them, or move them to Default automatically.Section and every task inside it disappear permanently.
30Unsaved-changes warning on drawer close

What is wrong: Closing the task drawer with unsaved edits discards them with no warning.

Why it is a bug: Clicking X loses the edit; clicking outside the drawer loses the edit AND navigates to the Projects list; Esc does nothing. A single misclick destroys a long description or checklist edit.

  1. Open any task drawer
  2. Change the name or description
  3. Click X, or click outside the drawer
  4. Reopen the task
Ask 'Discard unsaved changes?' before closing.Drawer closes instantly; the edit is gone.
37Add filter

What is wrong: On Work → Tasks, the 'Add filter' button is dead — clicking it never opens the filter popover.

Why it is a bug: Filters cannot be used at all on the Tasks page. (The same popover on a project's task list now works: checkboxes tick and Apply narrows the list — this used to be broken too.)

  1. Go to Work → Tasks
  2. Click 'Add filter'
  3. Click it again
Filter popover opens so a field and values can be chosen.Nothing happens — the button is a no-op.
77Deep-link to deleted project

What is wrong: Opening the URL of a deleted project renders a phantom project page instead of a 404.

Why it is a bug: The page shows a blank project with fake 'Jan 1, 2001' dates and an enabled Start timer — a user can even start a timer on a project that no longer exists.

  1. Delete any project
  2. Paste its saved URL back into the address bar
  3. Load the page
404 'Project not found' or a redirect to the Projects list.A phantom project shell renders: blank title, Jan 1–2 2001 dates, 0/0 tasks, live Start timer.
