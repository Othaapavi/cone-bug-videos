1Sidebar links go to the wrong pagemedium
N.2 · Chrome · 1366×768 · Fail (2/2)

What is wrong: The menu on the left has links like Projects and Dashboard. Their web addresses are built wrong.

Why it is a bug: If you right-click a menu link and choose 'Open link in new tab', you land on a wrong or broken page instead of the page you clicked.

Technical detail: Sidebar uses relative links (href='./work/projects'), so they change depending on the current page.

  1. Log in to Cone.
  2. Click Work > Projects.
  3. Hover the mouse over 'Projects' in the left menu and look at the address in the bottom-left corner of the browser: it shows /pm/work/work/projects (the word 'work' twice).
  4. Hover 'Dashboard': it shows /pm/work/dashboard.
  5. Open a project, hover 'Tasks': it points inside the project (/pm/work/projects/details/<id>/my-tasks).
  6. Right-click 'Projects' > Open link in new tab.
Each link opens its own page, also in a new tab.The new tab opens a wrong or empty/404 page.
